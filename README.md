# 课表截图 → 手机日历（kebiao-to-calendar）

截一张课表图 → 自动识别课程 / 老师 / 教室 / 星期 / 节次 / 单双周 → 生成 `.ics` 日历文件 → 手机点开「添加到日历」，**每节课上课前自动提醒**。

- 🔒 **不登教务、不输密码**：只要一张截图，不碰你的学校账号。
- 💻 **截图只在你自己电脑上识别**：默认用本地 OCR（RapidOCR，离线模型），不联网、不上传任何第三方。
- 🗓 **单双周 / 跳周都能处理**：`1-15周(单)`、`2-16周(双)`、`1-8,10-16周` 都会算成具体日期，并写成标准重复规则（RRULE）。
- ⏰ **提醒可调**：默认提前 10 分钟（VALARM），想提前多久自己改。
- 🏫 **作息自己改**：「第几节 → 几点」是一张可修改的时间表（`periods.json` 或网页上直接改）；如果截图里写了时间（如 `第1-2节 08:00-09:35`），会自动读出来。
- 🎌 **放假可跳过**：比如国庆 10/1-10/7 不上课，会写成 EXDATE，那几天不提醒。

> 支持大多数「格子式」课表截图（表头是星期一…星期日，左侧是第几节）。特殊排版识别不准时，可以在网页表格里直接改，或用下面的「AI 表格」方式。

## 快速开始

需要 Python 3.9+。

```bash
cd kebiao-to-calendar
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 方式一：网页版（推荐）

```bash
python app.py
# 浏览器打开 http://127.0.0.1:8765
```

1. 拖入课表截图 → 点「识别课表（本地 OCR）」→ 核对表格（可直接点格子改）；
2. 填开学日期（第 1 周）、提前提醒分钟数、节次时间表、放假日期 → 「展开单双周」看具体日期；
3. 点「生成并下载 课表.ics」。

想让手机直接下载：`python app.py --host 0.0.0.0`，手机和电脑连同一个 Wi-Fi，手机浏览器打开 `http://电脑局域网IP:8765`。
（`0.0.0.0` 会让同一局域网的人都能访问这个页面，用完记得关掉。）

### 方式二：命令行

```bash
python cli.py examples/sample_timetable.png --start 2026-09-07 --alarm 10 \
              --skip 2026-10-01:2026-10-07 -o 课表.ics
```

### 方式三：让 AI（Cursor / ChatGPT / 豆包…）读图，本工具负责算日期

把截图丢给你常用的 AI，用这段提示词：

> 这是一张大学课表截图。请把每节课的课程名、老师、教室、星期几、第几节、上哪几周，整理成一张 Markdown 表格，列名依次是：课程|老师|教室|星期|节次|周次。周次保留原文写法（如 1-16周、1-15周(单)、2-16周(双)）。同一格里有两门课要拆成两行。只输出表格。

把 AI 返回的表格粘贴到网页「粘贴 AI 返回的表格」，或保存成 `table.md` 后：

```bash
python cli.py --table table.md --start 2026-09-07 -o 课表.ics
```

（这种方式截图会发给你选的那个 AI 服务，隐私政策以该服务为准。）

### 可选：用你自己的多模态大模型识别

设置环境变量后，网页上会多出「用我配置的大模型识别」按钮（任何 OpenAI 兼容接口，包括本地 Ollama）：

```bash
export KEBIAO_LLM_BASE_URL=http://localhost:11434/v1   # 或你自己的云端接口
export KEBIAO_LLM_MODEL=llava
export KEBIAO_LLM_API_KEY=xxx                          # 本地模型可不填
python app.py
```

**开启后截图会发送到你配置的这个接口**，不配置就不会联网。

## 导入手机

把 `课表.ics` 发到手机（微信文件传输助手 / AirDrop / 邮件附件）：

- **iPhone**：点开 .ics →「添加全部」→ 选一个日历。建议新建一个「课表」日历，以后不要了可以整个删掉。
- **安卓**：各品牌略有不同，一般是用「日历」App 打开，或在 日历 → 设置 → 导入。部分机型需要先用文件管理器打开。
- 也可以导入 Google 日历 / Outlook 网页版，再同步到手机。

提醒是否弹出取决于手机日历的通知权限，请确认日历 App 允许通知。

## 隐私说明

- 不需要教务系统账号和密码，本工具也没有任何登录功能。
- 默认模式下截图只在本机处理：网页版上传到的是你自己电脑上运行的 `app.py`（127.0.0.1），识别完立即删除临时文件；不调用任何外部服务、不做统计、不存数据。
- 只有你**主动**配置了大模型接口（见上）或自己把截图交给某个 AI 时，截图才会发给那个服务。
- 第一次 `pip install` 时会从 PyPI 下载依赖和 OCR 模型（模型随 `rapidocr-onnxruntime` 包一起安装），之后识别不需要网络。
- 分享课表截图求助时，记得把姓名、学号打码。

## 目录

```
app.py                 网页版后端（Flask，只监听本机）
cli.py                 命令行版
periods.json           节次时间表（示例作息，按学校改）
web/index.html         单页前端
kebiao/recognize.py    本地 OCR + 表格版面识别
kebiao/parse.py        周次 / 节次 / 星期解析（单双周、跳周）
kebiao/ics.py          生成 .ics（RRULE 单双周、VALARM 提醒、EXDATE 放假）
kebiao/table.py        解析 AI 返回的 Markdown / CSV 表格
kebiao/llm.py          可选：自配大模型识别（默认关闭）
examples/              虚构示例课表（学校、老师、课程全部是编的）
tests/                 单元测试（用 icalendar 校验 .ics 能被解析）
```

```bash
pip install pytest

```

## 已知限制

- 只支持「格子式」课表；列表式（一行一门课）的截图请用「AI 表格」方式。
- 一节课跨越两个大节格子、手写体、严重倾斜/模糊的截图可能识别不准，请在表格里核对。
- 默认时区 Asia/Shanghai。
